# 清屏（Android 16 / Java）— 零基础教程

## 这是什么版本？
这是一个可在 Android Studio 中打开的 Java 项目，使用 Android AccessibilityService 监听部分界面变化，扫描可访问的界面文本，并将疑似广告相关文字线索保存在本机。

**它不是完整广告拦截器。** 当前版本不会移除广告控件、阻止网络请求、自动点“跳过”、关闭其他 App 或阻止跳转。关键词命中只是线索，不代表真正拦截成功。模拟记录会明确标记为“模拟”。

## 一、准备电脑
1. 在电脑安装 Android Studio（官方渠道下载）。
2. 打开 Android Studio，首次启动时按提示安装 Android SDK。
3. 在 SDK Manager 中安装 Android 16 / API 36 SDK。
4. 安装 Android SDK Platform-Tools（如果想用 USB 调试）。
5. 使用 JDK 17。Android Studio 通常可使用自带的 Gradle JDK。

## 二、打开项目
1. 解压 `QingPing_Android16_Java.zip`。
2. Android Studio 选择 **Open**。
3. 选择解压后的 `QingPing_Android16_Java` 文件夹（里面能看到 `settings.gradle`）。
4. 等待 Gradle Sync 完成。若提示安装缺少的 SDK，选择安装。
5. 运行前确认 SDK API 36 可用。

## 三、在手机上运行
1. 手机打开“设置 → 关于手机”，连续点击“版本号”以启用开发者选项（不同品牌路径略有不同）。
2. 在开发者选项中开启“USB 调试”。
3. 用 USB 数据线连接电脑，并在手机上允许这台电脑调试。
4. Android Studio 顶部设备列表选择手机，点击绿色 Run（三角形）。
5. 应用安装后打开“清屏”。

也可以先用 Android Studio 的 Device Manager 创建 Android 16 模拟器。

## 四、启用真实界面线索检测
1. 在“清屏”里点击 **开启/管理无障碍服务**。
2. Android 系统会打开无障碍设置。
3. 找到“清屏界面线索检测”并由你本人手动开启。
4. 阅读系统权限提示，确认理解后再授权。
5. 返回清屏，状态应显示“系统设置中已开启”。
6. 打开其他 App 的界面，若系统向本服务提供了可读取的文本，且文本含有关键词，应用就会新增一条“检测线索”记录。
7. 回到清屏查看记录。

## 五、测试统计界面
点击 **添加一条【模拟】测试记录**。统计里的“模拟测试记录”应增加 1。这条记录只用于测试，不代表系统真的识别或拦截了广告。

点击“清空本地记录”会删除本应用保存的统计数据。

## 六、重要限制
- 无障碍服务必须由用户在系统设置中明确开启；应用不能自行开启。
- Android、手机厂商和目标 App 都可能限制服务能读取的界面内容。
- 使用自绘画布、游戏画面、WebView、加密/隐藏内容的页面，可能没有可读文本。
- “广告”“跳过”等词也可能出现在普通页面中，因此会误报；广告也可能完全不含这些词，因此会漏报。
- 进程被系统或厂商省电策略停止时，服务可能暂停；用户关闭无障碍权限后必然停止。
- 该项目没有开机广播。无障碍服务的生命周期由 Android 系统管理，通常在用户启用后由系统绑定；不保证重启后在所有设备上都持续可用。
- 该服务请求读取活动窗口内容，因此只能安装和测试于你信任的设备。不要用它收集他人屏幕内容；本项目仅在本地保存记录，不上传数据。
- 如果要公开发布，必须诚实说明无障碍用途、隐私处理与检测局限，并遵守 Google Play 和目标应用的政策。

## 七、常见问题
### Gradle 同步失败
确认网络可访问 Google Maven/Gradle 仓库、Android Studio 使用 JDK 17，并且已安装 SDK Platform 36。必要时在 Android Studio 中点击 Sync Project with Gradle Files。

### 找不到服务
先运行一次应用，然后进入系统设置的无障碍页面查找“清屏界面线索检测”。部分品牌会把已下载应用的服务放在子菜单中。

### 显示已开启但没有记录
这是可能的。当前代码只检测有限关键词，而且有些 App 不会向无障碍服务暴露页面文本。可先用模拟记录确认统计界面正常。

### 可以生成 APK 吗？
Android Studio 同步成功后，选择 **Build → Build Bundle(s) / APK(s) → Build APK(s)**。构建完成后点击提示里的定位链接找到 APK。首次构建若报错，请把完整错误信息发来再排查。
